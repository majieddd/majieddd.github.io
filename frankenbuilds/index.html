Listing verification status

The site ships with a refresh system that re-checks every listing over a real browser and rewrites the data file. A build is only shown as purchasable when every line is in stock at the quantity the build needs.

Components, compared

Every part the builds are made of, with its live listing, price, and the stats that decide a build: memory bandwidth, VRAM, watts, slots, channels. Sorted by the metric you pick. Prices are the verified asking price on the live listing.

$ / GB/s = price ÷ memory bandwidth (lower is better). $ / GB VRAM = price ÷ VRAM.

Price history

Every tracked component is re-priced from its live listing once a day. Each card plots the asking price over time and the same series normalized to the unit you actually buy — $/GB of VRAM for a GPU, $/GB of RAM for memory, $/W for a supply, $/GPU-slot for a board, frame, riser or shroud — so a $75 card and a $22 board can be compared on what is getting more expensive.

Hover a chart to read a day's exact price. The dashed line is the series average. A flat chart means the component has only been recorded for one day so far — the history grows one point per day.

Throughput formula
total = (GPU HBM bandwidth × GPU count) + system DDR bandwidth. DDR = channels × 8 bytes (64-bit channel) × MT/s ÷ 1000. 8-channel DDR4-2400 = 153.6 GB/s; 16-channel DDR4-2666 = 341.1 GB/s.
