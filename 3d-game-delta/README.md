# INKFALL: Siege of the Avalon Yard

A 3D tower defense painted in comic ink and watercolor space (avorion cel-shade pack +
Everspace 2 painterly nebulas). Three.js r128 with hand-written GLSL shaders, textures
authored in Blender 4.5.1, music and sound composed in WebAudio. Single file, no install,
no network calls, run it from the browser above. Drag to orbit, wheel to zoom,
click hex pads to build. Keys: 1/2/3 speed, Space pause, M mute.

- 6 towers: RAIL LANCE, PLASMA PELT, TESLA ZEPHYR, FORGE MORTAR, BEACON SENTINEL, SAW KITE
- 5 enemies + the Carrion boss: gnat, borer, vaal gyro drone, gullwing frigate, carrion broodmother
- 3 waves. The deck keeps the ink of every battle (persistent splat decal system).
