# Research Archive

Material in this directory is preserved for provenance, reproducibility, and future analysis. It is not automatically binding canon.

- `prompts/` contains the current reproducible Deep Research prompt.
- `raw/` contains the attached session report in its original structure, wrapped only with a non-canon notice.
- `archive/phase-1/` contains the xeno, religion, ocean, craft, NARA archive, and taxonomy research package.
- `archive/phase-2/` contains the five-faction addendum, evidence workbook, game-system research, and prompt snapshot.
- `data/research/` contains normalized sortable source, taxonomy, and artifact inventories.

Session-native citation markers inside raw reports may not resolve outside the original research environment. Verify them against `docs/research/source-ledger.md` and primary sources before reuse.

Canon promotion requires an explicit fictional synthesis, an update to the maintained `docs/` page, any affected machine-readable data mirror, and a changelog entry.
