# Black Vault Research Route
## How to mine a massive archive without confusing document authenticity with claim validation

# 1. Scope

The Black Vault describes its broader archive as containing millions of government-document pages. Its dedicated UFO Files Search Engine is a narrower collection of documents, images, videos, and downloadable release packages. A literal page-by-page scrape is not the optimal research strategy for this project.

The useful objective is a **case-and-concept graph** connecting:

- agencies;
- dates;
- witnesses;
- sensors;
- locations;
- reported forms and behaviors;
- official resolutions;
- classification and redaction history;
- later folklore;
- faction interpretations;
- game scenarios.

# 2. Evidentiary rule

A government record can prove that a report, investigation, meeting, photograph, request, or claim existed. It does not automatically prove that the event was extraterrestrial, interdimensional, or technological.

Every extracted item should preserve four separate fields:

1. **Record authenticity** — is the document itself genuine?
2. **Claim provenance** — who made the claim and when?
3. **Phenomenon status** — what can be established about the event?
4. **Interpretation status** — how strong is any proposed explanation?

# 4. Seven-axis evidence ladder

Score each axis from 0 to 3. Keep the scores separate rather than producing one “alien likelihood” number.

| Axis | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| Provenance | Unknown repost | Traceable copy | Official release | Authenticated original with custody |
| Witness chain | Anonymous retelling | Named later recollection | Contemporaneous witness | Multiple independent contemporaneous witnesses |
| Sensor chain | None | Uncalibrated or incomplete | One calibrated system | Independent calibrated sensor types |
| Corroboration | None | Same-source repetition | Independent observers | Independent locations and systems |
| Conventional analysis | None | Informal speculation | Documented alternatives | Strong elimination with preserved data |
| Residual anomaly | Vague | Unusual but nonspecific | Specific unexplained behavior | Repeatable or instrumentally constrained anomaly |
| Attribution | Pure assertion | Broad category guess | Narrow hypothesis | Recoverable direct evidence of operator |

# 5. Record schema

Each archived item should become one structured record containing:

- internal record ID;
- source URL;
- archive and agency;
- incident date;
- document date;
- release date;
- location;
- medium: air, sea, space, ground, consciousness;
- morphology;
- behavior;
- sensors;
- witnesses;
- official resolution;
- alternative explanations;
- redactions and missing attachments;
- seven evidence scores;
- source tier;
- relevant rabbit-hole tags;
- interpretation by each of the five factions;
- possible scenario seed.

# 6. High-value case archetypes

## Tehran 1976

Use for military intercept, radar and visual claims, reported equipment effects, and competing electronic-warfare interpretations.

## Strategic nuclear clusters

Use because Federation, Machines, Xenos, and human disinformation all have plausible but different motives.

## AAWSAP/AATIP technical papers

Use as a vocabulary library for warp metrics, wormholes, metamaterials, programmable matter, invisibility, negative energy, and advanced propulsion. The existence of an official commissioned paper is not proof that the technology worked.

## Remote-viewing Mars

Use to show that an authentic government record can contain extraordinary perceptions without validating them. In the setting, remote viewing may receive physical reality, symbolic material, future probabilities, or Machine-inserted imagery.

## MJ-12 and Project Beta

Use as models of archival contamination. A forged committee name may hide a differently named program. Human disinformation can spread false alien stories to protect ordinary classified activity or obscure a separate anomaly.

## Project Blue Book

Use for a campaign-spanning archive in which most cases are ordinary, some are data-poor, a few remain genuinely difficult, and later factions cherry-pick whichever subset supports their agenda.

# 7. Research stop rules

- Stop expanding a claim when every source loops back to one anonymous post.
- Preserve the first appearance separately from later embellishment.
- Never count reposts as independent corroboration.
- Record when a page summarizes a document it does not provide.
- Distinguish missing information from positive evidence of concealment.
- Preserve contradictory versions; contradiction is often the most useful lore.
- Separate “unresolved” from “unexplainable.”
- Separate “authentic document” from “true claim.”
