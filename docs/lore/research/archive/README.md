# Superseded Research and Lore Drafts

These folders preserve the long-form materials that preceded the maintained wiki. They are included so collaborators can recover source trails, original data, discarded options, and earlier wording without forcing that volume into the canonical reading path.

- `phase-1/` — the complete original package contents: taxonomy in Markdown/CSV/JSON, religion-control map, orphaned-ocean technology, craft design, early 2099 synthesis, bibliography, official UAP notes/manifest, NARA helpers, package index, README, and use note.
- `phase-2/` — the complete addendum contents: research dossier, five-faction campaign draft, rabbit-hole atlas, Black Vault route, video-species extraction, game-system blueprint, source-evidence CSV/XLSX, prompt snapshot, README, and source manifest.
- `../raw/` — the attached deep-research report preserved essentially as received.
- `../prompts/` — the latest prompt maintained for reproducibility.

Nothing in this archive is binding merely because it is present. Promote changes through the maintained `docs/` pages and update the machine-readable data mirrors.
