# Editorial Style

## Voice

Write like an intelligence dossier translated into a playable universe bible:

- precise;
- declarative;
- skeptical about evidence;
- imaginative about fiction;
- never apologetic for mystery;
- never breathless about rumor.

## Keep core pages lean

A core page should answer:

1. What is it?
2. What does it want?
3. How does it conquer?
4. What makes it internally unstable?
5. How does the game express it?

Long source histories belong in research pages.

## Naming

- Prefer one canonical name and one meaningful alias.
- Do not create names merely to make a paragraph sound richer.
- Capitalize formal factions, offices, protocols, and named systems.
- Use `Xeno` only for political alignment.
- Use `Machine` for the faction class and `robot` only for the live code ID.

## Player-facing copy

- Creed: 3–9 words.
- Tagline: one sentence.
- Blurb: 45–90 words.
- Do not explain evidence labels in battle dialogue.
- Present faction confidence; preserve ambiguity in dossiers and codex entries.

## Research language

Use “the source claims,” “the record documents,” “the case remains unidentified,” or “later lore adds.” Avoid “proves,” “confirms,” and “the government admitted” unless the cited record actually supports those words.
