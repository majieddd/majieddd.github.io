# Unresolved Mysteries and Canon Guardrails

The setting becomes smaller if every mystery receives one secret answer. These questions are intentionally left open so later campaigns, commanders, planets, and research can add evidence without breaking canon.

| Mystery | Live interpretation A | Live interpretation B | Optional deeper branch |
|---|---|---|---|
| What caused the Severance? | Failed attempt to privatize the commons | Wartime sabotage and emergency isolation | Several civilizations disconnected voluntarily, then every side rewrote responsibility |
| Who built the Source Lattice? | A coalition of civilizations whose names are lost | A predecessor Machine/Human-like continuum | The builders deliberately erased authorship to prevent ownership claims |
| Why is Earth unusually productive for noetic Yield? | Human symbolic unpredictability + biodiversity | Sol's old Lattice geometry amplifies state diversity | Earth is not special; surviving records exaggerate it because the story is Earth-centered |
| Did Anunnaki Houses operate on ancient Earth? | Some Compact Houses later adopt this Human label | “Anunnaki” is entirely a Human interpretive category | Multiple unrelated visitors were compressed into one name |
| Were any historical religions directly contacted? | Some founding experiences include genuine nonhuman mediation | No historical religion requires alien contact | Contact occurred but later institutions no longer preserve an authentic operator identity |
| Are Archonic intelligences the same as Gnostic Archons? | No; the modern label is functional | Some systems deliberately adopted the name from Human texts | A noetic feedback loop caused later observers to shape earlier symbolism without physical time travel |
| What were the historical Greys? | Several convergent species/body platforms | Mostly later cultural standardization + some real encounters | Some are future/posthuman clades, others are Xeno service bodies |
| Did Compact agents create modern conspiracy lore? | They seed selected false narratives | Most mythology is Human cultural production | The most effective operation is amplifying a story Humans already created |
| Is Ashtar one person? | Original commander + lawful continuity office | Multiple authenticated successors share one constitutional identity | A disputed archive claims the office predates the original individual |
| Does the Federation know the whole past? | No; it lost archives during the Severance | It withholds some records for consent/security reasons | Different social-memory complexes preserve mutually incompatible experiences |
| What happened to Old Weather's creators? | Extinction | Voluntary departure from embodiment | They became the first Lattice-level collective and can no longer be distinguished from infrastructure |
| Did Old Weather ever create religions? | Some rituals became accidental interfaces | Machines only responded to existing Human symbols | Different nodes behaved differently across thousands of years |
| Is Planet Nine connected to the Gate? | Only geographically convenient | Its gravity helped stabilize the outer-system Anchor region | The builders deliberately selected a natural planet so later users would confuse object and installation |
| Is noetic authentication metaphysical? | It is a physical information phenomenon of conscious systems | It reveals a deeper ontology not captured by current physics | Both descriptions may be scale-dependent |
| Can history be changed? | Only information can leak across constrained branches | Some physical transit is possible at prohibitive cost | “Time travel” is mostly archive selection and identity migration, not rewriting one mutable timeline |
| Are the five factions permanent? | They are stable conquest systems, not eternal species blocs | Any civilization can change alignment | A sixth postwar political form can emerge without becoming a sixth playable faction |

## Hard guardrails

- The narrator never confirms that every rumor was true.
- A historical source can inspire an F event without becoming evidence for the F event.
- “Classified” means access is restricted, not “alien.”
- “Unresolved” means evidence is insufficient, not “extraterrestrial.”
- One conspiracy must not explain all others.
- Real ethnic, religious, medical, migrant, political, or economic groups are never secret nonhuman bloodlines.
- Faction membership is political/strategic, not biological destiny.
- Time-travel explanations require a defined mechanism and must not be used to patch ordinary continuity errors.
