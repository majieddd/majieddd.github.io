## Global archive rules

- A case has an **incident date**, **record date**, **release date**, **translation date**, and **local-ingestion date**.
- The most famous case is not automatically the strongest case. Searchability, language, media access, and cultural templates shape fame.
- A named event can contain multiple unrelated observations. Event Segmentation Doctrine runs before attribution.
- Witness sincerity, witness memory, sensor integrity, and external ontology are scored separately.
- Official investigation establishes official attention, not alien origin.
