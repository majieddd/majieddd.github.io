# Contaminated Legends

A contaminated legend can be false as presented while preserving a real operational detail from another event. That does not authenticate the legend.

| Legend | Research judgment | Safe fictional salvage |
|---|---|---|
| MJ-12 | Serious provenance and formatting problems; archival possession is not authentication | Forgers copy the format of a real continuity compartment but invent its alien mission |
| Bennewitz / Project Beta / Dulce | Real people, disputed manipulation, sincere interpretation, and later mythology are entangled | False alien-base coordinates conceal a deep sensor installation watching Old Weather activity |
| Project Serpo | Anonymous Internet provenance and recursive citation | Invented exchange details accidentally reuse data from a classified astronomy mission |
| Ummo | Anonymous letters and hoax attribution with a sprawling secondary corpus | A real observer later hides inside the known hoax format |
| Solar Warden | Unsupported secret-fleet disclosure lore | The name belonged to a sensor-fusion network, not a fleet |
| TR-3B | Weak technical provenance around exotic propulsion claims | A real classified triangle and an unrelated field experiment are merged in memory |
| Black Knight | Conflation of unrelated radio, satellite, and imagery stories | The legend is maintained to draw attention away from a smaller probe elsewhere |
| Eisenhower treaty | Retrospective accounts without contemporaneous treaty evidence | A continuity exercise supplies phrases later reused in treaty folklore |
| Valiant Thor | Traceable contactee literature, not Pentagon confirmation | A real diplomatic codename is reused by several Federation avatars |
| Men in Black | Multiple folklore, human, hoax, and channeled ontologies | Humans, noetic avatars, and fraudsters copy the same archetype deliberately |
| Project Blue Beam | Unsubstantiated 1990s conspiracy tradition | Real projection and electronic-warfare research is exaggerated into a total fake apocalypse |
| Nazi UFO / Antarctic base | Genuine wartime aerospace history fused with unsupported survival and alien-base claims | An abandoned polar signals installation is mistaken for the legendary base |
| Lacerta Files | Weak Internet provenance | Stolen Old Weather geological data is embedded in a false reptilian interview |

## Use rule

A fictional salvage detail must come from a **different** verified or clearly fictional layer. Never write, “the hoax was true after all.” Write, “the hoax contaminated the search for something else.”
