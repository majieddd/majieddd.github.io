# Archive War Mission Seeds


These missions convert real records and source-history problems into gameplay without declaring their extraordinary interpretations true. Each mission names the source layer and an exact live commander, battlefield, world kind, or tower family so writers can move directly from research to scenario design.

## Use rule

The historical event supplies an evidence problem, not a secret answer. The future plot may add a displaced operational truth, but the source card must display where the historical record ends and the F adaptation begins.
