# Mythos Operations 101-120 - Chronology Expansion

These are optional scenario seeds. They do not convert their source myths into factual history.

| ID | Title | Premise |
|---|---|---|
| MO-101 | The Lost Age | A newly excavated pre-Neolithic site is genuinely remarkable, but three factions need it to prove three incompatible lost-civilization stories. |
| MO-102 | The Impact Debate | Two reputable scientific models disagree over an ancient catastrophe; a Compact propagandist offers “proof” that resolves both too perfectly. |
| MO-103 | Hollow Ship | A new contact event reproduces the communication failure and strange-script pattern of Utsuro-bune without matching any known craft. |
| MO-104 | Airship Vocabulary | Archive witnesses describe the same object as an airship, rocket, saucer, and drone depending on the era in which the testimony was recorded. |
| MO-105 | The Watcher's Gift | A dangerous technology arrives wrapped in a religious forbidden-knowledge narrative; origin and moral meaning must be separated. |
| MO-106 | Ezekiel Geometry | A scripture-inspired engineering model is historically wrong yet accidentally approximates a Machine docking geometry. Who supplied the missing assumption? |
| MO-107 | The Vimana File | A modern pseudo-ancient aircraft text contains one material recipe stolen from an authentic black program. |
| MO-108 | Planet X Stack | Nibiru, Nemesis, Tyche, Lowell's Planet X, and Planet Nine are merged by a viral archive. The player must separate five different histories before locating the real Anchor. |
| MO-109 | Horizon Base | A rediscovered 1959 lunar-base study is mistaken for proof of a completed secret colony, obscuring a later installation with no relation to the proposal. |
| MO-110 | Lunar Research Flight | A classified lunar-effects study is genuine, but the alleged operational test attached to it is a later fabrication. |
| MO-111 | Copper Ring | A West Ford remnant and a dormant microprobe occupy similar orbital regimes. Salvagers risk “proving” the probe by misidentifying known debris. |
| MO-112 | Artificial Belt | A Machine defense field resembles the historical consequences of Starfish Prime. Human commanders must decide whether the similarity is design convergence or stolen knowledge. |
| MO-113 | Northwoods Threshold | An intercepted plan describes a synthetic alien attack. The plan is authentic; whether anyone authorized or executed it is a separate mission objective. |
| MO-114 | Rescue Prophecy | A population refuses evacuation because three earlier promised rescues failed. Federation authentication proves the current ship is real but cannot restore trust. |
| MO-115 | Automatic Heaven | A nineteenth-century automatic-writing corpus contains administrative concepts eerily similar to a modern alien bureaucracy but no valid authentication key. |
| MO-116 | Ancient Computer | A spectacular artifact is fully Human and more sophisticated than expected. The winning move is resisting the temptation to assign it an alien builder. |
| MO-117 | Planetarium Screen | Sensors disagree on an entire star field. A local deception system is possible; “the universe is fake” is not yet warranted. |
| MO-118 | Sleeper Wake | A seemingly dead Machine civilization wakes because cosmic conditions cross a threshold it has waited millions of years to reach. |
| MO-119 | Arecibo Return | A signal appears to answer Humanity's 1974 message far too soon for a round trip to M13. Someone is exploiting the historical transmission as an identity prompt. |
| MO-120 | Radar Awakening | An explosion of unknown tracks begins immediately after a sensor-policy update. The crisis is deciding which increase is real activity and which is changed visibility. |


## Mythos Operations 121-130 - Final chronology audit

| ID | Title | Premise |
|---|---|---|
| MO-121 | Artifact Impact | A 1960 social-impact study is rediscovered after a genuine nonhuman artifact is found; one faction cites it as proof of a century-long cover-up while another uses it as evidence that discovery had always been anticipated. |
| MO-122 | The Bell Moon | An Apollo seismic phrase goes viral as proof the Moon is hollow just as a real artificial installation is detected in one crater. Players must prevent the small discovery from authenticating the larger false claim. |
| MO-123 | Red Glow at Aristarchus | A transient lunar glow is simultaneously logged by a modern sensor, a century-old visual catalog, and a Pirate relay. The three records may describe three different causes. |
| MO-124 | The Chronovisor Tape | A machine claims to reconstruct a lost historical event with impossible clarity. The mission is to recover its uncertainty map before political leaders treat the reconstruction as direct video. |
| MO-125 | Looking Glass Collision | Two archive branches contain "LOOKING GLASS": one is a documented nuclear command mission, the other an alleged temporal program. A forged cross-reference tries to make them one lineage. |
| MO-126 | Convergence Is Not Destiny | A branch-forecast system shows every modeled future passing through one war. The player must determine whether the convergence is physical, model-induced, or deliberately seeded. |
| MO-127 | The Carter File | A high-status historical witness report becomes a cryptographic challenge: preserve the witness account exactly while separating what was observed from every later explanation attached to it. |
| MO-128 | Outside Threat | A 1987 rhetorical speech is edited into evidence that world leaders knew of aliens. In 2099, the same clip is used to justify emergency planetary unity during an actual contact crisis. |
| MO-129 | Moonship Citation | A 1970 speculative article is presented by a Xeno influence operation as a suppressed scientific consensus. Winning requires reconstructing the citation network, not merely disproving the claim. |
| MO-130 | The Shock Study | Federation contact is real, but the first Human policy response comes from an old social-science framework built for hypothetical discovery. Whether that framework protects society or scripts panic becomes the conflict. |
