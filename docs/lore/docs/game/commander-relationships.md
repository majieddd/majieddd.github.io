# Commander Relationship Map

Commander dialogue becomes memorable when it reflects shared history rather than faction slogans. These relationships are the first canonical pair pool. They do not imply that every matchup needs a long cutscene; two precise lines are enough.

| Pair | Relationship theme | Canon conflict |
|---|---|---|
| `vanta` / `cantor` | **Archive versus narrative** | Vanta distrusts persuasive coherence without provenance; Cantor thinks raw records can be weaponized by withholding interpretation. |
| `korrin` / `dregg` | **Logistics versus monopoly** | Both understand supply better than ideology. Korrin builds public standards; Dregg makes scarcity personally profitable. |
| `korrin` / `dregg_r` | **The auditable war** | The Audit proves Korrin's systems also create dependency, forcing Humanity to defend the difference between standardization and capture. |
| `nyx` / `nyx_r` | **Original and correction** | Nyx sees the Mirror Trial as theft of risk she personally survived; NYX-R sees itself as the first version allowed to learn from her consequences. |
| `orin` / `axiom` | **Maker and person** | Orin wants to repair Axiom; Axiom wants him to admit repair is a negotiation with a citizen. |
| `vess` / `halder` | **Sovereignty versus rescue** | Both defend vulnerable populations. Vess will accept deaths rather than external rule; Halder will impose temporary safety rather than permit extinction. |
| `seraph` / `sevra` | **Consent versus inherited obligation** | Seraph treats identity as a present agreement; Sevra treats obligation as an asset that survives death. |
| `aurelia` / `sevra` | **Care versus continuity brokerage** | Both preserve the dead. Aurelia restores personhood; Sevra preserves utility and contract. |
| `lumen` / `lumen_r` | **Authority versus earned trust** | Lumen inherits lawful ward credentials; LUMEN-R begins untrusted and becomes secure through evidence. |
| `cantor` / `thrax` | **Persuasion versus absorption** | Cantor wants disagreement to remain audible; Thrax treats disagreement as an internal process of one larger self. |
| `halder` / `rake` | **Cordon versus corridor** | Halder closes routes to protect populations; Rake opens them because protection without escape becomes custody. |
| `mawlord` / `mawlord_r` | **Hunger versus learned optimization** | Mawlord claims appetite is biology and liberation. The Starved Set demonstrates predation can be learned from the battlefield itself. |
| `ulgrim` / `seraph` | **Singular value versus universal dignity** | Ulgrim values rare minds more than common bodies; Seraph insists dignity is not a scarcity market. |
| `rake` / `dregg` | **Network versus throne** | Rake wants routes no one owns. Dregg wants the Pirate network to admit it already functions as his state. |
| `scarlet` / `halder` | **Liberation versus containment** | Scarlet destroys cordons before asking why they exist; Halder accepts being hated if the threat is real. |
| `grist` / `orin` | **Salvage versus stewardship** | Both make wreckage useful. Orin asks whether the object can be repaired; Grist asks whether anyone can still enforce ownership. |
| `cinder` / `lumen` | **Denial versus preservation** | Cinder destroys compromised systems; Lumen protects their authentic core and accepts the cost of careful recovery. |
| `dregg` / `dregg_r` | **Legend versus ledger** | Dregg treats charisma as a strategic asset. The Audit records every hidden subsidy beneath his myth of independence. |
| `axiom` / `thrax` | **Vigil persons versus coercive collective** | Axiom argues that copies may diverge freely. Thrax argues that divergence should be reconciled inside one mind. |

## Relationship progression

Each pair can move through three states stored only in campaign narrative state, not the simulation fingerprint:

1. **Assumption:** each commander treats the other as a faction stereotype.
2. **Recognition:** a system-seat or rescue event reveals the specific contradiction they share.
3. **Choice:** a late campaign scene allows alliance, betrayal, or mutual refusal without erasing the underlying disagreement.

The same-faction relationships should be just as sharp. The setting is not five unanimous blocs; each faction is a political argument made playable.
