# Mythos Operations

This registry converts the source-genealogy work in the [Alien and Space Mythos Atlas](../research/alien-space-mythos-atlas-2026.md) into **74 optional campaign, Archive War, dialogue, and world-dossier premises**. These are fiction hooks, not statements that the source conspiracies are true.

## Use rules

1. Keep the five factions unchanged.
2. Retain the source evidence class in any dossier that invokes a real tradition.
3. Never map a real ethnic, religious, national, medical, or political population to an alien bloodline.
4. Preserve one conventional and one speculative reading until a mission intentionally resolves the question.
5. Mythos Operations do not alter mechanics until a separate implementation and balance pass.
