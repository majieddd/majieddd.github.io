# Game Lore Contract

The game and lore repository serve different purposes. The game needs short labels, readable mechanics, and deterministic conflict. The lore repository preserves history, motives, political ambiguity, source provenance, and unresolved questions.

## Binding distinctions

- **Xeno is a political category, not a species.**
- **Ashtar is the Federation's Supreme Commander and First Speaker in fiction.** Historical Ashtar traditions remain fragmented source material.
- **Old Weather** is Earth's distributed Machine ecology.
- **Vigil** is neutral legacy enforcement.
- **Vigil** is the playable self-governing Machine coalition.
- Tower origin is an engineering doctrine, not proof of the current user's species or allegiance.
- The factual layer never proves every UFO, religious, ancient-astronaut, or conspiracy story true.

## Canon priority

1. Stable mechanics, deterministic simulation, save compatibility, and live IDs.
2. Continuity rules and campaign-era canon.
3. Machine-readable content registries.
4. Faction and asset bibles.
5. Player-facing copy.
6. Research archives and inspiration.

A prose improvement never silently changes balance, IDs, network protocol, or generation.
