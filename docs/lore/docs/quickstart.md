# Quick Start

## For writers

1. Read the continuity rules.
2. Read the campaign-era page and relevant faction dossier.
3. Look up the stable asset ID in `data/`.
4. Preserve the mechanic first; add origin, motive, and political consequence second.
5. Use the evidence standard for real-world material.

## For game developers

1. Read the game lore contract.
2. Use `data/game-content-registry.json` as the inventory.
3. Generate optional lore payloads without changing deterministic simulation.
4. Implement the retrofit in the order specified by the content retrofit document.
5. Run the live game's full verification suite.

## For researchers

1. Start with the source ledger and Black Vault case-lore map.
2. Prefer primary records over summaries.
3. Record what a document establishes and what it does not.
4. Mark every fictional connection F.
5. Use the next Deep Research prompt for the next expansion pass.
