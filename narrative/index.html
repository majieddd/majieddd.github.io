Playable spin-off

COSMIC CONQUEST: RELIQUARY is a standalone low-poly 3D tower defence set in this universe and painted in the same Neon Reliquary language: faceted geometry lit so that every triangle reads as a palette-knife stroke, hued shadows, ink outlines and screen-print grain. It shares the roster, the factions and the wave curve with the main game, and shares no code with it. Fourteen towers, ten reactions, twenty waves, three boards, five commanders, WebGL2, zero dependencies.
